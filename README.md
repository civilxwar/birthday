# Birthday System Experience

Mini birthday surprise app in the style of a fake system console.

## Run locally

Open the project in a browser, or serve it locally:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000

## How it works

- Boot sequence intro
- Recovery screen with a cipher puzzle
- Final birthday message and surprise page

## For a real `.exe`

This is a static web app, so it can be deployed as a website or later wrapped into an installer for desktop use with Electron or similar.
